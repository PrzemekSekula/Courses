# IBM Quantum Computing Courses
--- 

Notebooks created while taking the following courses: 
- [Practical Quantum Computing with IBM Qiskit for Beginners] (https://www.coursera.org/learn/packt-beginners-guide-to-practical-quantum-computing-with-ibm-qiskit-w6mos/) (folder: `beginner`)
- [Quantum Computing with Qiskit and Advanced Algorithms](https://www.coursera.org/learn/packt-quantum-computing-with-qiskit-and-advanced-algorithms-wils7) (folder `advanced`).



### Practical Quantum Computing with IBM Qiskit for Beginners
This is a standalone course, focused mainly on understanding gates. The original code is available for downloading, but the course is quite old, the Qiskit worked differently, when I was taking the course. 

### Quantum Computing with Qiskit and Advanced Algorithms
This is a third course in the [The Complete Quantum Computing Course for Beginners Specialization](https://www.coursera.org/specializations/packt-the-complete-quantum-computing-course-for-beginners). It is mainly focused on algorithms. See the filenames for more.
